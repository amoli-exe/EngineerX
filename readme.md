# EngineerX 4.0 — Event Portal

A modern, responsive, and minimalist web portal for **EngineerX 4.0**, organized by Graphic Era Hill University in collaboration with Tech Geeks.

---

## 🚀 Features

- **Minimalist & Clean UI**: Light theme with subtle borders, clean typography, and uncluttered layout.
- **Interactive 3D Flip Cards**: Click **"Details"** on any card to view dates, venue, rules, entry fees, and coordinator contacts.
- **Standardized 9:16 Posters**: Built-in responsive `9:16` aspect ratio container with `object-fit: contain` to prevent poster cropping across laptops, desktop viewports, and mobile devices.
- **Direct Registration Links**: Quick Google Form links embedded on both the front and back of each event card.
- **Independent Logo Sizing**: Separate classes for each partner and event logo for easy maintenance and scaling.

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure.
- **CSS3**: CSS Grid, Flexbox, custom variables, and 3D transforms (`preserve-3d`, `rotateY`).
- **Vanilla JavaScript**: Lightweight inline script toggling flip card states.

---

## 💻 Getting Started

1. Clone or download the repository.
2. Ensure image assets are placed inside the `assets/` folder.
3. Open `index.html` in any modern web browser or run via Live Server in VS Code.
